## 🌟 Featured Projects

### 🧺 [Laundry Hub](https://github.com/abdullahalnuman0/laundry-services) — Full-Stack Marketplace

A multi-role on-demand laundry marketplace: one Android codebase serving **customer, shop owner, and rider** apps through Gradle product flavors, backed by a Spring Boot API.

- **Android**: Kotlin, Jetpack Compose, Material 3, MVVM, Hilt, clean architecture (presentation / domain / data)
- **Backend**: Java, Spring Boot 3.4.5, Spring Security + JWT, Spring Data JPA, MySQL
- **Integrations**: Stripe payments with webhooks, Google Maps + reverse geocoding, WebSocket real-time updates
- **Highlights**: Email/OAuth auth with OTP, map-based address management, nearby shop discovery, item-level cart, 15-stage order lifecycle, multi-payment support (card, cash, bKash, Nagad)

### ✅ [TaskFlow](https://github.com/abdullahalnuman0/task-manager) — Android Task Manager

A native task manager with reminders that actually fire — exact alarm scheduling via `AlarmManager` that survives Doze mode.

- **Tech**: Kotlin, Jetpack Compose, Material 3, Clean Architecture + MVVM, Hilt, Room, DataStore, Coroutines & Flow
- **Highlights**: Dashboard with completion stats, categories with custom icons, subtask tracking, recurring task rescheduling, timeframe filtering

### 🔢 [Sudoku Game](https://github.com/abdullahalnuman0/sudoku-game) — Kotlin Multiplatform

A cross-platform Sudoku running on **Android, iOS, and Desktop** from a single Kotlin codebase.

- **Tech**: Kotlin Multiplatform, Compose Multiplatform, MVVM, Koin, SQLDelight, DataStore, Coroutines
- **Highlights**: Puzzle generation with guaranteed unique solutions, four difficulty levels, pencil-marks mode, hints, undo/redo, auto-save, light/dark theme

### 🔌 [Arduino Controller](https://github.com/abdullahalnuman0/arduino-controller) — Bluetooth Hardware Control

An Android app that pairs with HC-05/HC-06 Bluetooth modules to control Arduino-powered LEDs, motors, and sensors.

- **Tech**: Kotlin, Jetpack Compose, MVVM, BluetoothAdapter/BluetoothSocket, Coroutines
- **Highlights**: Custom command buttons, real-time sent/received message log, dark & light theme, downloadable APK
